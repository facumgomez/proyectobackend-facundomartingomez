# Ecommerce Backend

Este repositorio contiene el backend de un sistema de e-commerce, desarrollado como parte de mi portfolio técnico en desarrollo backend.

---

## 📌 Descripción

Este proyecto consiste en un backend desarrollado con Node.js y Express que provee una API para un sistema de e-commerce.
Incluye la lógica de negocio necesaria para la gestión de productos, usuarios y operaciones básicas de compra.

El objetivo del proyecto es demostrar conocimientos en desarrollo backend, estructuración de proyectos y creación de APIs REST.

---

## 🛠️ Tecnologías utilizadas

- Node.js
- Express
- JavaScript
- MongoDB
- Mongoose
- Handlebars
- Git y GitHub

---

## 🧩 Funcionalidades

- Gestión de productos (CRUD)
- Gestión de usuarios
- Manejo de carritos de compra
- Endpoints REST
- Arquitectura organizada por capas
- Persistencia de datos con MongoDB

---

## 🚀 Ejecución local

1. Clonar el repositorio  
   git clone https://github.com/facumgomez/proyectobackend-facundomartingomez.git

2. Instalar dependencias  
   npm install

3. Configurar variables de entorno en un archivo .env

4. Iniciar el servidor  
   npm start

El servidor quedará disponible en el puerto configurado (por defecto http://localhost:8080).

---

## 🔗 Integración

Este backend está preparado para ser consumido por un frontend de e-commerce mediante peticiones HTTP.
